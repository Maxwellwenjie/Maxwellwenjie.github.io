## CANFD驱动和助手下载

凌界软件中心下载CANFD驱动，并找IT下载ZCANPRO  
![[Pasted image 20251216092423.png]]  
![[Pasted image 20251216092427.png]]  
使用说明：  
1、需要填写DataID项  
a、使用普通CheckSum：DataID填写生命信号的起始位（十六进制），CheckSum默认位置生命信号后面一个字节  
b、使用EEA3.0(B11)：DataID填写200  
c、使用EEA3.5(A12)：DataID填写201  
2.使用E2E需要在ZCANPRO安装根目录放置DataID文件，文件名为“DataId_车型.txt”  
例如：DataId_A12.txt、DataId_B11.txt  
3、文件可找我要

## ZCANPRO操作：

1、设备类型选择USBCANFD-200U(可以看电脑的设备管理器)，选择你所连接的通道，这里是通道0  
![[Pasted image 20251216092447.png]]  
2、启动后选择仲裁域和数据域的速率，分别是500kbp和2Mbps  
![[Pasted image 20251216092452.png]]  
3、新建DBC视图，加载DBC文件，DBC文件可找我要。  
![[Pasted image 20251216092457.png]]  
![[Pasted image 20251216092501.png]]  
![[Pasted image 20251216092509.png]]  
4、观察HPCBCM_22B消息名，关注第32个信号，CANFD报文发送成功后“解防”将变为“设防”。  
![[Pasted image 20251216092515.png]]  
![[Pasted image 20251216092520.png]]  
5、新建DBC发送视图，找到ZCUB_22E,右键添加到右侧。首先选择CANFD类型，E2E选择“是”，DataID设置为201，发送次数设置为-1(一直发送)或者1(发送一次)，然后设置CANFD报文将序号6设置成短按，序号12设置成Lock。设置好后点击发送，这时DBC视图中的“解防”变为“设防"。  
![[Pasted image 20251216092527.png]]  
![[Pasted image 20251216092531.png]]  
![[Pasted image 20251216092536.png]]  
![[Pasted image 20251216092541.png]]  
6、远程登录板子，找到lpADS可执行文件(./bin./lpADS)，并将其改名(mv ./bin./lpADS ./bin/lpADS_bk)，防止开机lpADS自启动,然后将lpADS进程杀死，最后重启板子。  
7、查看日志，将唤醒线(信号连接线器1的pin5引脚)断开，半分钟左右板子进入休眠状态，再将唤醒线连接上时板子会立即唤醒。  
![[Pasted image 20251216092546.png]]

## 注意

板子休眠的过程中不同组件休眠唤醒的时机不同，例如：soc要比viu提前休眠，更晚唤醒，这会造成soc接收原始uss数据丢失
